# apartment-bot

Telegram-бот, который периодически собирает объявления об аренде квартир с **Kufar** и **Onliner** и отправляет новые варианты в чат.

## Как это работает

1. Каждые **30 секунд** бот запрашивает объявления у источников.
2. Результаты приводятся к единой модели `Apartment`.
3. Кеш в памяти (`ApartmentCache`) отфильтровывает уже виденные объявления.
4. На **первом** запуске бот только наполняет кеш и **ничего не отправляет** (чтобы не заспамить чат текущей выдачей).
5. Со следующих циклов в Telegram уходят только новые объявления.

## Требования

- [Node.js](https://nodejs.org/) (LTS)
- [pnpm](https://pnpm.io/) (`npm i -g pnpm`)
- Telegram-бот и chat id, куда отправлять сообщения

## Быстрый старт

### 1. Установка зависимостей

```bash
pnpm install
```

### 2. Настройка `.env`

В корне проекта создай файл `.env`:

```env
TELEGRAM_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id

SEARCH_CITY=minsk
SEARCH_MIN_PRICE=1
SEARCH_MAX_PRICE=450
SEARCH_ROOMS=1,2,3,4
SEARCH_PAGE_SIZE=10
```

Как получить значения:

- **TELEGRAM_TOKEN** — создай бота через [@BotFather](https://t.me/BotFather), скопируй токен.
- **TELEGRAM_CHAT_ID** — id чата/пользователя, куда бот будет писать.
  Узнать можно через [@userinfobot](https://t.me/userinfobot) или аналоги.
  Перед запуском напиши своему боту `/start`, иначе он не сможет отправить сообщение.

Файл `.env` уже в `.gitignore` — не коммить токены.

### 3. Запуск

```bash
pnpm dev
```

Команда запускает `tsx watch src/index.ts`: бот стартует и перезапускается при изменении кода.

В консоли увидишь что-то вроде:

```text
Получено: 20
Новых: 0
[]
```

На первом цикле `Новых: 0` — это нормально. Новые объявления появятся после следующих проверок.

## Настройка фильтров поиска

Фильтры задаются в `.env` и используются и для Kufar, и для Onliner. После изменения перезапусти бота.

| Переменная | Описание | Kufar | Onliner |
|---|---|---|---|
| `SEARCH_CITY` | Город (`minsk` и т.п.) | да | нет |
| `SEARCH_MIN_PRICE` | Минимальная цена в USD | да | да |
| `SEARCH_MAX_PRICE` | Максимальная цена в USD | да | да |
| `SEARCH_ROOMS` | Число комнат через запятую, например `1,2,3,4` | да | да |
| `SEARCH_PAGE_SIZE` | Сколько объявлений брать за один запрос | да | да |

Интервал опроса меняется в `src/index.ts` (`setInterval(..., 30000)` — миллисекунды).

## Структура проекта

```text
src/
  index.ts                 # точка входа, цикл опроса
  models/
    apartment.ts           # общая модель объявления
  parsers/
    kufar/                 # парсер Kufar (api, mapper, types)
    onliner/               # парсер Onliner (api, mapper, types)
  services/
    aggregator.ts          # объединение источников + фильтры
    apartment-cache.ts     # дедупликация новых объявлений
  telegram/
    formatter.ts           # HTML-текст сообщения
    telegram.ts            # отправка в Telegram API
```

## Полезные замечания

- Кеш хранится **только в памяти**: после перезапуска бот снова «забудет» отправленные объявления и на первом цикле снова только прогреет кеш.
- Дедупликация идёт по ключу `source:id`, поэтому одинаковые id у разных площадок не конфликтуют.
- Сообщения отправляются с `parse_mode: HTML`.
- Если не заданы `TELEGRAM_TOKEN` / `TELEGRAM_CHAT_ID`, отправка упадёт с ошибкой.
